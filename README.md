## Description
Philosophers is about threads, processes, mutexes, and semaphores 
it models the classic "Dining Philosophers" problem there is number of Philosophers and there is one fork between each pair of philosophers.
each philosopher should eat in time to eat and it should hold 2 forks.

## Instructions
- Download the project from 42 intra
- Make sure that there are no norm errors
- Compile using `make`, which produces the `./philo` executable
-Run the program with the following format :
./philo number_of_philosophers time_to_die time_to_eat time_to_sleep [number_of_times_each_philosopher_must_eat]
